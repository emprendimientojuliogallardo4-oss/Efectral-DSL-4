# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-30

### Added
- Primera versión estable oficial de **Efectral DSL** (`.efd`).
- Meta-lenguaje formal, tipado y determinista para Sistemas Agénticos e Inteligencia Artificial.
- Núcleo normativo: arquitectura ISA para prompts cognitivos (`@`, `!`, `$`, `->`, `SiFalla`).
- Validador y linter de referencia: `tools/efc_validator.py` (`efc`).
- Soporte para entornos IDE (VS Code, Cursor, Windsurf, Antigravity) con gramática TextMate y snippets.
- Colección de ejemplos canónicos y patrones de seguridad (`examples/`).
- Pipeline de Integración Continua (CI) mediante GitHub Actions.
